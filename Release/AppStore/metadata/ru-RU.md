## Описание

YPoints — помощник для ведения счёта и материалов матча в падел.

Следите за очками по системе 0–15–30–40, геймами, сетами и тай-брейком. Добавляйте игроков из Контактов, а при игре рядом синхронизируйте табло между двумя iPhone по Bluetooth.

Находите ближайшие корты на карте. Добавляйте к результату снимок с камеры или из Фото, записывайте короткую голосовую заметку и сохраняйте карточку счёта в медиатеку.

Личная статистика открывается после Face ID или код-пароля. Виджет на экране блокировки позволяет быстро посмотреть состояние матча, а уведомления — настроить напоминание.

Разрешения запрашиваются только при использовании соответствующей функции. При отказе основное ведение счёта остаётся доступным.
