## Description

YPoints helps you keep score and organize match materials for padel.

Track points using the 0–15–30–40 system, along with games, sets, and tie-breaks. Add players from Contacts and synchronize the scoreboard between two nearby iPhones over Bluetooth.

Find nearby courts on the map. Add a match photo from the camera or Photo Library, record a short voice note, and save a score card to Photos.

Open private statistics with Face ID or the device passcode. Check the current match state on the Lock Screen widget and set a match reminder with notifications.

Permissions are requested only when you use the related feature. Core scorekeeping remains available if you decline a permission.
